# actorgamebox
Experimentation with artificial actors playing games.

# Installation
The user needs to install the following:

* gymnasium
* ale_py
* autorom

You can install these requirements via:

```
pip install -r requirements.txt
```

# Getting Atari Game ROMs from ALE
Run the following after installing `ale_py` and `autorom`:

```
AutoROM
```

This will prompt the user to accept a license agreement, and install the ROMs in a desired location for the user.
